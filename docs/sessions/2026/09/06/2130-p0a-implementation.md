# P0a-01：結晶1個の試遊実装

## 依頼と範囲

Issue #1。ユーザーが引用した初回依頼に沿って、Localの同じフォルダにUnityプロジェクトを作成し、P0aで試遊の区切りを設ける。P0bは今回含めない。

## 開始状態と環境

- main `6983e80`、未コミット変更なし。`git pull --ff-only`で一致確認後、`feat/p0a-crystal`へ分岐。
- Unity 6000.3.18f1（5ebeb53e4c07）、Windows standaloneモジュールあり。別途6000.5.6f1も存在するが使わない。
- Unityで解決したURP 17.3.0をmanifestにも固定。Windows x64 / Mono、.NET SDK 10.0.302（計算テスト）。
- 描画実行機器：AMD Radeon RX 7900 XTX / Direct3D 12。

## 実装

- 3部位、4基本技、集中力32、10%会心、分離・致命傷・品質・一度だけの回収。仕様の仮数値をJSONに分離。
- 対象が乱数状態と加工状態を保持。UI開閉で再生成しない。打撃中の二重入力・回収・放棄を排他。
- 同じseed／別seedの試遊リセット、2回確認で放棄。結果は試遊用で終了すると消えることを表示。
- 結晶メッシュ、Kenneyの岩・打撃音・粒子、日本語フォント、3D部位番号、選択ハイライト、つるはしの動き、画面揺れ弱／なし、音量調整。
- 工房・カバン・経済・永続セーブは未実装。P0全体が完成したとは扱わない。

## 実行した検証と修正

- `dotnet run --project tests/MiningRules.Tests.csproj`：13,173アサーション合格。帯両端、分離直前／成立、致命傷直前／成立、品質ランク境界、会心の中心止めと品質非悪化、集中力不足／0、無操作報酬なし、二重入力／回収、放棄後回収不可、seedの再現性。
- Windowsビルド・描画実行。自動試遊はUIボタンの処理を通し、開閉前後の集中力・ゲージ・乱数一致、品質100の上質回収、二重回収拒否、致命傷、放棄、リセットを確認。
- 1280×720と1920×1080の実スクリーンショットを確認。技名の欠落を行の高さ修正で解決。状態文の重なりを全面背景カメラの追加で解決。表示中の日本語テキストのレイアウト検査合格。
- 音声出力サンプルが非ゼロ（ピーク0.5655705）。最初の取得方法では拾えなかったためAudioListenerの出力も測定。聴感・音の気持ちよさの人間評価とは区別する。
- 最初のビルド失敗はGUI/Text ShaderをAlways Includedに加えたことで内部専用シェーダーが混入したため。ログのHideFlags.DontSaveを特定し、設定から除去して成功。URPマテリアルはResources内の参照素材としてビルドへ含める。
- Computer Useで通常起動と画面表示を確認。ウィンドウにユーザー入力が検出され、加工・選択の変化を観測したため、こちらからの操作を控えた。エージェントによるOS入力一巡の合格とは記録しない。

## 未検証

- ユーザーの楽しさ・打撃の気持ちよさ・会心の分かりやすさの評価。
- 他PC、長時間プレイ、16:9以外の比率。設定はP0aでは永続化しない。
- P0bの取引・帰還・セーブは未実装なので未検証。

ゲームソースをコミット後、操作中のウィンドウを妨げない別フォルダ `builds/P0a-01-final` に同じP0a-01を再ビルドする。正式なソースID・PR・最終検証結果はCURRENTと後続の報告コミットに記録する。機能ブランチのまま保存し、mainへ統合しない。
