# 鍛冶再現の参照・未確認台帳

2026-09-07。参照台帳。対象は担当者が選定した無印DQ11 PS4版。呼称はユーザーの許可により「活性度」を使用。実装状況はCURRENTを参照。

P0a-03の暫定実装は `game/Assets/Resources/ForgeCalibration.json` に未確認係数を集約した。原作の数値表ではない。全技・地金効果の分岐は実装しても、以下の未確認項目が解決したことにはならない。試験用レシピ6種の対象値・素材数・宝珠数も原作データの完全移植ではない。

## 資料

- ユーザー提供の「ふしぎな鍛冶」本文。システム・DQ11・PS4版・特技一覧を使用。原文全体をリポジトリへ転載しない。
- [ふしぎな鍛冶](https://wikiwiki.jp/dqdic3rd/%E3%80%90%E3%81%B5%E3%81%97%E3%81%8E%E3%81%AA%E9%8D%9B%E5%86%B6%E3%80%91)：2026-09-07の確認でもPS4／3DSの違い、2000℃以上の威力上限を確認。温度自体はさらに高くできる記述がある。
- [ねらい打ち](https://wikiwiki.jp/dqdic3rd/%E3%80%90%E3%81%AD%E3%82%89%E3%81%84%E6%89%93%E3%81%A1%E3%80%91)：DQ11は会心率7倍と記載。記事による公式ガイドの紹介であり、ガイド現物を今回確認したわけではない。DQ10オフラインの2倍を混ぜない。
- [極限・ふしぎな鍛冶](https://dq11.org/dq11_kaji.html)：上下・4連・斜め1.2倍、みだれ0.8倍の補足。
- [攻略レポート](https://darage.com/dq11/kazi.html)：実プレイを基にした記録。レベル・集中力の表、各対象の地金値、てかげんの会心の記録、温度調整の扱いを照合する資料。温度650〜1000の観測幅を、1000℃だけの厳密な乱数表へ変換しない。
- [Blender公式・コマンドライン](https://docs.blender.org/manual/en/latest/advanced/command_line/index.html)、[Python実行の引数](https://docs.blender.org/manual/en/5.1/advanced/command_line/arguments.html)：外部からスクリプトを渡して実行し、レンダリング等を自動化できる根拠。現在の作業環境で接続済みという意味ではない。

## 誤った監査記述の訂正

前回監査の通常打撃「1000℃で基準22前後」はユーザー提供本文に記載がなく、裏付けのない判断だった。現行コードの18〜26という値と、原作の値を混同しない。今回訂正した。攻略レポートには別の温度帯の観測値があるが、正確な分布・端数処理が分かるまで原作の基準値を確定しない。

## 原作比較の記録ひな形

対象版／モード、装備、レベル、地金効果、各部位の操作前値、温度、集中力、技、各打撃の数値と会心、操作後の温度・集中力・部位値、詳しくみる評価、仕上げ結果、資料または画像への参照。

原作の値が読めない場合は、読み取れた範囲と推測を分ける。比較用ビルドで乱数を固定するのは自作実装の再現性確認であり、原作と同じ乱数を使った検証とは限らない。
