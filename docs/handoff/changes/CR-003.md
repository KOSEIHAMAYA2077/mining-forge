# CR-003：DQ11鍛冶を再現する基準版

更新：2026-09-07。状態：このタスクでP0a-03へ実装・検証中。ユーザーは資料だけでなくこちらで再現するよう再度明示。呼び名の一致は不要で、温度相当は「活性度」を採用する。正確な確率・品質係数等が未確認のため、完全再現の完了とは扱わない。

## 最新の依頼と優先順位

ユーザーの指示：まず完全な再現を作り、そこへ後から要素を足す。前作モデルの使い回しは必須ではない。鉱床の殻が剥がれる表現は将来案として残すが、今回は保留。

したがって、CR-002の「表示改修を先行」「P0a-02の判定・数値を維持」「Lucent Kitを主な実装案にする」は次回作業の指定から外す。採掘への翻案をいったん止め、鍛冶ミニゲームそのものの比較基準を作る。旧ゲームとビルドは履歴として保持する。

参照機種は**無印DQ11・PS4版**。ユーザーが調査・選択を担当者に委ねたため、最初の添付画面と機種差を踏まえて選んだ。3DS版・DQ10・DQ11S固有の処理を混ぜない。

## 再現する範囲

鍛冶の準備から仕上げ、うちなおしまでの操作・ルール・見え方・打撃のテンポを再現する。ユーザーの明確化により、温度の表示名は「活性度」でよい。ラベルや題材の一致よりシステムの一致を優先し、名称変更を理由に効果量や規則を変えない。

レシピ選択 → 素材投入 → たたく／とくぎ／くわしくみる／しあげる → 条件成立時にひっさつ → 品質と完成品・宝珠 → 所持品のうちなおし。

採掘固有の横打ち、分離条件、破損フラグによる品質上限39、未分離で完成品なし、母岩の露出率はこの基準版へ持ち込まない。原作にない常時の数値予測や乱数表示は比較用の開発表示へ分離し、標準操作を再現する画面の前提にしない。

RPGの探索、戦闘、物語全編は今回の「鍛冶の再現」の対象ではない。レシピ・レベル・素材などの入力を用意する比較用メニューを使ってよい。そのメニューは原作再現部分と区別する。全レシピを作る前でも検証は始められるが、技・地金効果・評価の種類を削って完成扱いにはしない。

## 地金効果

1. 戻る：ランダムな1部位の鍛えた量が減る。中心一致の部位は対象外。過打の部位が戻る可能性も含める。
2. 威力変化：次の打撃の2倍と半減が交互に発生。
3. 集中力変化：消費半減と、消費1.5倍・会心率上昇が交互に発生。
4. 部位強化：1部位の威力と会心率が上昇。

初期1000℃、加熱で節目へ着地する場合、200℃境界を跨ぐだけの場合、0℃到達時、効果を加熱で流す場合、必殺と重なる場合を分けて照合する。単純な「4手ごと」の実装では温度調整に追従しない。

## 未確認値を再現済みにしない

[参照・未確認台帳](CR-003-REFERENCE.md)に、基本打撃の離散値と丸め順、会心率表、必殺チャージ率、装備ごとの品質係数・閾値、地金効果の詳細、熱風の計算順などを記録した。前回監査の「1000℃で通常打撃22前後」は提供本文に根拠がなく撤回する。

既知のUI・全技・状態遷移などは進めてよい。必要な未確認パラメータは設定と出典状態を分け、仮設定を使った試作は「再現作業中」と表示・報告する。仮値を使うことと、対象版の完全再現を達成したことは別。仕様の大きい部分を黙って削って不明値を回避しない。

## 見た目と素材の方針

前作Lucent Kit、CR-002の青い結晶画像、Kenneyは候補であり必須ではない。より適した新規モデル・配布素材・自作素材を選んでよい。今回は地金を叩く操作の見え方を揃えることを優先し、青い鉱床・殻剥がしの制作を先に始めない。

参考画像の操作配置、枠の読みやすさ、対象とゲージの対応、中心一致でゲージが橙色になる表現などを再現する。画像・音源・キャラクターモデルの抽出はせず、画面に必要な素材は制作または利用可能なものを採用する。RPGの背景人物を全身実装することを鍛冶操作の前提にはしない。

Blenderが使える場合は、形状・材質・照明を制作してレンダリングを確認し、Unityへ必要な形で出力する。接続を待たないと判定ロジックやコマンドを作れない構造にしない。今回の環境にはBlender専用ツールがなく、PATHと標準インストール先にも実行ファイルを確認できていない。未接続のBlenderで制作したと報告しない。

## 完成の確認

以下を実装チェックと原作照合に分けて報告する。自作実装のテストに通るだけでは原作との一致の証明にはならない。

- 14操作すべてについて、対象範囲・消費・温度・乱数・会心・節目効果への影響を確認する。
- 中心未満／一致／超過、会心で中心へ届く／届かない、会心ミス、てかげんの会心を比較する。
- みだれ打ちの4打撃を順番に解決し、同一マス3回制限と、途中で中心到達した後の処理を確認する。
- ひっさつチャージ、使用、範囲技、加熱での消費、再使用不可を確認する。
- 地金効果4種類をそれぞれ持つ対象、複数の盤面形状、低・中・高レベルで確認する。
- 品質の各境界、新規作成で未打撃の仕上げ、うちなおしで強化／据え置き／上限、宝珠と素材の一度だけの増減を確認する。
- 通常画面・特技ページ・選択・打撃・中心一致・節目効果・途中評価・仕上げ確認・結果を1280×720と1920×1080で実見する。キーボードとマウス両方、音も聴いて確認する。
- 原作との照合記録に機種、レベル、装備、温度、技、結果を残す。ランダム結果は1回一致しただけで確率分布まで一致としない。
- 未確認台帳の未解決項目、比較対象外にしたRPG周辺機能、実装した代替素材を報告する。
