## 今回の追加フィードバック

ユーザーは、添付のDQ11鍛冶画面に近いものをまず触りたかったと明確化。「たたく・特技・詳しく見る・採取する」という操作を希望。鉱石のフリー素材を再調査し、必要なら自作する余地もある。採取以外や敵への応用も着想として挙げたが、今回の題材変更を決めたわけではない。

現行実装は初期仕様に沿っている一方、初期仕様が空間的な盤面とコマンドの構造を簡略化しすぎていた。主役の素材を差し替えるだけでは技の判断は増えない。

## 次版で揃えるもの

1. 2Dの一画面に、対象の形を持つ2列×4行の盤面。結晶1種で6マスを使う。
2. たたく／特技／詳しく見る／採取するのコマンド階層。
3. 単体・横2・縦2・2×2など、位置と巻き込みが違う技。
4. 温度に相当する「活性」一変数と、活性を上下させる技。予測値を毎手表示する。
5. 各マスのゲージ、会心、途中評価、採取終了、局所的な欠けと打撃・音の仕上げ。

以前の「盤面だけ先に、状態変化は必要なら後」という比較順を、ユーザーの意図に合わせて変更する。今回は参考の操作構造が揃った基準版を先に作る。活性なしとの比較は同じ盤面の開発用設定で可能にする。

配置・技の数値・活性という名称・損傷ルールは設計担当の仮設定。ユーザーがこれらの細部を確定したことにはしない。実装担当はまずこの具体案で確認し、調整の根拠を記録する。

## 独自要素の候補は次の比較へ残す

「対象によって守りたい部位が違う」を有力候補とする。部位をうまく残すと結晶の素材量、遺物の固有効果、魔力の回収量へつながる方向。スキルセットや敵への応用は候補のまま。独自ルールを加えて参考の操作感を確かめる機会を飛ばさない。
