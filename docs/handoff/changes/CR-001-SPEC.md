# CR-001詳細：P0a-02「形のある盤面を加減して採る」

2026-09-06。状態：次回実装へ渡す設計。今回は文書のみ更新。基準となるゲームはP0a-01 / `ef89cd0`、前回の報告は `d8a249f`。実装は `feat/p0a-crystal` / PR #6で継続し、mainへ自動統合しない。

## 目的と優先順位

ユーザーがまず望んでいた、DQ11の鍛冶に近い「コマンドを選び、対象の形に沿ったマスとゲージを攻略し、途中評価を見て仕上げる」体験を揃える。単なる3本のゲージの装飾変更ではない。以下の操作構造を実装し、数値は独自の仮値として調整する。参考作品の全技・全イベント・数値の完全再現はこの仕様の完成条件ではない。

一つの結晶、一画面の2D採取、固定の技セットを作る。Unityの現在の版を維持し、ゲームエンジンを変更しない。P0b、探索、工房、敵、持ち込みスキル、独自の追加ルールには進まない。

## 1. 画面とコマンド

左に4コマンド、中央に結晶と2列×4行の盤面、各マスに対応するゲージ、上に状態値、左下に集中力、下に選択中の説明と結果を置く。

```text
┌コマンド─────┐        活性 1000 / 効果倍率 1.00
│ たたく       │    Aのゲージ ┌ A ┬ B ┐ Bのゲージ
│ 特技         │    Cのゲージ ├ C ┼ D ┤ Dのゲージ
│ 詳しく見る   │    Eのゲージ ├ E ┼ · ┤
│ 採取する     │    Fのゲージ └ F ┴ · ┘
└──────────┘       対象の形に沿う結晶と母岩
集中力 120 / 120     技の作用範囲・到達予測・消費・説明
```

配置は説明用。小さい画面でも数値やゲージが重ならないよう調整する。画像を右側に置いて左の表だけを操作する構成へ戻さず、対象物・作用位置・ゲージが対応する画面にする。

| コマンド | 動作 |
| --- | --- |
| たたく | 単体の基本技を選び、マス選択→決定で実行 |
| 特技 | 技一覧を開く。範囲・倍率・消費を表示し、技→位置→決定で実行 |
| 詳しく見る | 現在の品質、各マスの進み具合、未分離、損傷、今採取した場合の結果を表示 |
| 採取する | 現在の結果を予告して確認し、採取を終了する |

マウスとキーボードの両方で操作可能にする。矢印でメニュー・位置移動、Enterで決定、Escで一段戻る。メニューや詳細の開閉、選択、取り消しには集中力・活性・乱数を使わない。位置の確定前に採取を進めない。演出中の重複決定は一回だけ受理する。

「閉じる」「放棄」「試遊リセット」「設定」は主コマンドとは分ける。閉じて再開すると全状態と乱数を保持する。放棄と終了による報酬なしの扱いは明示する。

## 2. 盤面

2列×4行の8位置を固定の枠として持つ。次版の結晶は以下の6マスを使用し、点は対象のない空き位置。マス数を増やす基盤を先に汎用化しないが、配列添字だけでなく行列と有効位置をデータで保持する。

| 行 | 左列：IDと中心 | 右列：IDと中心 |
| --- | --- | --- |
| 1 | A：50 | B：80 |
| 2 | C：80 | D：50 |
| 3 | E：110 | 空き |
| 4 | F：110 | 空き |

全マス初期値0、適正帯は中心±5、分離ラインは下端−15。中心線を帯の中に描き、ぴったり到達と帯に入ったことを視覚上区別する。次版の品質計算では帯内を同じ満点とし、中心ぴったりの追加報酬はまだ設けない。

空き位置にゲージや報酬を置かず、採取・品質の計算から除外する。有効マス同士の配置が技の意味を決める。完成したマスも再度叩けるため、範囲技の巻き込みがリスクになる。

## 3. 固定の技セットと仮数値

初期集中力120。数字は6マス用に再設定し、旧版の32を流用しない。基本技は「たたく」、残りは「特技」へまとめる。

| 技 | 作用範囲 | 活性1000での基本効果 | 集中力 | 会心 |
| --- | --- | --- | --- | --- |
| たたく | 選択1マス | 18〜26 | 5 | あり |
| 強打 | 選択1マス | 36〜52 | 8 | あり |
| そっと削る | 選択1マス | 9〜13 | 3 | なし |
| 横打ち | 選択位置と右隣 | 各18〜26 | 8 | あり |
| 縦打ち | 選択位置と下隣 | 各18〜26 | 8 | あり |
| 四点打ち | 選択位置を左上とする2×2 | 各18〜26 | 14 | あり |
| 活性を上げる | 対象全体の状態値 | 活性+300、最大2000 | 8 | なし |
| 活性を鎮める | 対象全体の状態値 | 活性−200、最低0 | 4 | なし |

範囲技は全ての作用位置が有効なときだけ実行できる。盤面外・空き位置を含めば不可にし、理由を表示する。位置の暗黙の反転、空き部分の無料無視、単体技への自動変換はしない。前記の盤面では横打ちはAまたはC始点、四点打ちはA始点、縦打ちはA・C・E・B始点で使える。

集中力不足は実行不可。状態調整は上限・下限で値が変わらない場合も実行不可。現在200未満での鎮静は0まで下げる。調整技はマス選択不要、効果と消費を確認して確定する。

## 4. 温度に対応する「活性」

基準版でも温度に相当する変数を含める。結晶に残る力が高いと削れやすく、操作によって落ち着いていくという仮の説明で「活性」と呼ぶ。現実の結晶の物性を主張する名称ではない。世界観はここでは固定しない。

- 対象全体で一つの値T。初期1000、範囲0〜2000。
- 打撃系の1行動を実行した後に50低下。複数マスでも一度だけ。
- 効果倍率は `0.5 + T / 2000.0`。T=1000で1.00、T=2000で1.50。
- 効果は行動前のTを使う。各マスで基本範囲から整数を独立抽選し、倍率を掛けた後に切り捨てる。
- 調整技は表の増減のみ適用し、追加の−50はしない。マス値は変えない。
- T=0では打撃系は不可。集中力が足りれば活性を上げて続けられる。足りなければ現状で採取終了か放棄を選ぶ。
- 現実の時間経過、メニュー操作、詳細表示ではTが変わらない。

「活性700・倍率0.85」「この打撃後は650」のように現在と次を表示する。各技の予測範囲もTで更新する。隠れた補正にしない。

会心は該当技で、対象マスの行動前の値が中心未満の場合に各マス独立で10%。倍率適用後の通常量を2倍にし、中心を越える場合は中心で止める。中心以上から会心は出ない。会心抽選順は有効マスの行優先・左から右で固定し、プレビューで乱数を進めない。

範囲技は行動前の状態から全マスの結果を計算し、全結果を適用し、最後にTを下げる。手前のマスの演出で後ろのマスの倍率が変わる実装にしない。

## 5. 詳細・採取・失敗

「詳しく見る」は無料で何度でも使える。各部位の現在値・中心・帯・分離の可否・損傷を一覧で確認できる。詳細を見ないと必要な情報が全く分からない設計にはせず、通常画面にもゲージ、選択技の予測、集中力、Tを常時表示する。

旧版の「一マスが致命傷なら即座に全体終了」は、次版では変更する。削りすぎはその場で結果を示し、続けるか終了するかを選べるようにする。

- 各マスの損傷線は適正帯上端+20。到達でそのマスを「破損」とし、以後回復しない。破損しても技の作用対象には残る。
- 品質点は帯内100、帯より下は `max(0,100−2×不足量)`、帯より上は `max(0,100−5×超過量)`。有効マスの平均を四捨五入する。
- 破損マスが一つでもある場合、対象全体の品質を最大39へ制限し、「破損部位があるため損傷品」と明示する。
- 「採取する」はいつでも選べる。未分離マスが残る場合は報酬なしで終了する旨を確認表示。全て分離済みなら現在品質の原石を1個だけ得る。
- 無操作で採取終了しても原石や欠片は得られない。
- 集中力0でも分離済みなら採取できる。残りの操作がない場合にUIで終わり方を案内する。

品質80以上＝上質、40〜79＝通常、39以下＝損傷品を維持。DQの装備評価をそのまま名乗らず、採取の報酬に接続する。本仕様では遠征全体の全損ルールは足さない。

## 6. プレビューと手応え

技→位置選択時に作用する全マスを枠で囲み、各ゲージへ通常の到達範囲を描く。会心時の到達範囲は別の印と10%表記で示し、最大値だけを必ず出る結果のように見せない。未分離の解消見込み、帯越え、破損線越えを数値と記号で区別する。

一つの大きな結晶と母岩が盤面の裏に見えるようにする。各マスの進行に合わせて、その位置の母岩の被覆が減る。帯を越えると芯に亀裂が出る。全体の画像を一様に縮めるだけでは完成としない。

対象の絵、コマンドの枠、技の範囲表示、ゲージ、打撃位置が揃って見えることを優先する。Kenney背景の導入だけで見た目が完成したと扱わない。背景と主役の画風を統一し、DQの画像・音・装飾を抜き出して使わず、このゲームの絵と配色で作る。

音は少なくとも打撃、繊細な削り、会心、帯到達、帯越え、破損、回収を聞き分けられるようにする。複数マス同時処理で効果音を無制限に重ねず、打撃音に状態音を短く添える。同時発生の優先は破損→帯越え→会心→帯到達とし、他の状態は該当マスの視覚表示に残す。

背景はKenneyのRoguelike Caves & Dungeonsが第一候補。鉱石は [素材調査](../../research/2026-09-06-forging-reference-and-ore-assets.md) の候補から実物を見て選ぶ。適合しなければ結晶1点と状態差分を制作する。素材選定に時間をかけすぎず、ASSETSに実際の導入と候補を区別して記録する。

## 7. 実装と検証の区切り

内部の作業順は、座標を持つ盤面→コマンド・範囲技→活性と調整→結果・詳細→2D表現と音。ユーザーへ渡すP0a-02はこれらが揃った一画面とする。途中のロジックだけで完成と報告しない。

開発用に活性固定1000の比較モードを用意し、通常のゲームメニューとは分ける。これは同じ盤面・技で状態変化の有無を比較するためで、ユーザーが温度相当を不要と言ったことにはしない。

動作確認：メニューを戻ってもコストや乱数が動かない／範囲外・空き位置を含む操作の拒否／完成マスも巻き込む／複数マスで活性低下は一度／状態調整と0・上限／倍率と切り捨て・会心順序／破損後も終了を選べる／未分離終了の無報酬／一度だけの回収／開閉保持と二重入力。

バランス確認は単なるアサーション数で代用しない。固定の盤面とseedを複数使い、状態調整ありで回収へ到達できるか、範囲技を使わない場合と使う場合に手順がどう違うかを確認する。回収不能のseedが多ければ集中力や中心値を調整し、その根拠を記録する。探索のための実装基盤や高度なソルバを新設する必要はない。

設計段階の試算例：各打撃の基本量を範囲の中央値とし、会心なしで、A始点の四点打ち2回→E始点の縦打ち4回→BとCへ強打各1回→E始点の縦打ち1回→E・F・A・D・E・Fへそっと削るを順に実行すると、全マスが適正帯内に入り、残り集中力18・活性250となる。これは一つの机上例で、実際のseedを使ったプレイの成功率やゲーム実行を検証したものではない。

ユーザーへ聞くこと：

1. 参考の「コマンドを選んで盤面を仕上げる」感覚に近づいたか。
2. 隣の状態によって横打ち・縦打ち・単体を選び直す場面があったか。
3. 活性を変えることで使いたい技や順番が変わったか。
